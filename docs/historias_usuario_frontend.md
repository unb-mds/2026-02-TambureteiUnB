Página Inicial 

**Tipo:** Feature
**Equipe:** Frontend
**Label:** *Frontend

### Descrição

Como estudante sem cadastro, quero acessar uma página inicial com uma visão geral dos dados acadêmicos da UnB, para compreender os principais indicadores e encontrar cursos ou disciplinas de interesse.

A página deverá apresentar uma visão geral da instituição e disponibilizar mecanismos de busca e filtragem para facilitar a exploração dos dados.
                                                                                                  Como estudante com cadastro, além de querer acessar a página inicial e a visão geral dos dados disponíveis do tamburetei, quero inserir arquivos como materiais de estudos para ajudar os estudantes que estão ingressando em determinada matéria que eu já conclui.      
                                                                                                  A página deverá apresentar uma visão geral da instituição, disponibilizar mecanismos de busca e filtragem para facilitar a exploração dos dados e disponibilizar um espaço para inserir materiais de estudos.
                                                                                        
### Tarefas

- Criar a página inicial do projeto no App Router
- Criar a estrutura visual do Dashboard
- Criar componentes para exibição das métricas institucionais
- Implementar campo de busca por curso ou disciplina
- Implementar filtro por campus
- Criar área para visualização dos indicadores acadêmicos
- Criar dados mockados para desenvolvimento do frontend
- Preparar estrutura dos componentes para futura integração com a API
- Criar botão de exportação do dataset
- Estilizar a página
- Garantir responsividade
- Tratar estados de carregamento e erro
- Criar testes para os principais componentes
- Criar um chat para os usuários se comunicarem e tirarem dúvidas

### Critérios de Aceitação

- A página inicial apresenta uma visão geral dos indicadores acadêmicos da UnB.
- O usuário consegue visualizar as principais métricas institucionais.
- O usuário consegue pesquisar por um curso ou disciplina.
- O usuário consegue filtrar informações por campus. 
- O usuário que possui cadastro consegue inserir materiais de estudos.
- A interface apresenta os dados de forma organizada e compreensível.
- A página possui estrutura preparada para receber os dados provenientes da API.
- O usuário consegue identificar a opção de exportação dos dados.
- A página é responsiva.
- Estados de carregamento e erro são tratados visualmente.

### Critérios de Teste

- Teste de componente validando a renderização das métricas.
- Teste de componente validando a busca por curso ou disciplina.
- Teste de componente validando o filtro por campus.
- Teste de componente validando a exibição dos estados de carregamento e erro.
