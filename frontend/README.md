# 📈 Tamburetei UnB — Frontend

Interface web moderna desenvolvida em **Next.js 16**, **React 19**, **TypeScript** e **Tailwind CSS** para visualização de métricas e histórico de disciplinas da Universidade de Brasília (UnB).

---

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
* [Node.js](https://nodejs.org/) versão 18 LTS ou superior
* [npm](https://www.npmjs.com/)

### 1. Instalar as dependências
```bash
npm install
```

### 2. Executar o servidor de desenvolvimento
```bash
npm run dev
```
Acesse a aplicação no seu navegador: **[http://localhost:3000](http://localhost:3000)**.

### 3. Scripts disponíveis
* `npm run dev`: Inicia o servidor local de desenvolvimento com *Hot Reload*
* `npm run build`: Compila e gera os artefatos otimizados de produção
* `npm run start`: Inicia o servidor Node.js com a build de produção compilada
* `npm run lint`: Executa a verificação estática de regras e boas práticas com ESLint
* `npx tsc --noEmit`: Realiza a validação estática de tipos TypeScript
